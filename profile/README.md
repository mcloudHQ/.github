## Projects

| | What it is | Built with |
| --- | --- | --- |
| **[mcloud](https://github.com/mcloudHQ/mcloud)** | A [Spicetify](https://spicetify.app) theme that turns the Spotify desktop app into Apple Music: a glass sidebar, a floating Liquid Glass player, a cover-art library and Spicy Lyrics controls. | JavaScript, CSS |
| **[mcloudfast](https://github.com/mcloudHQ/mcloudfast)** | A native Spotify client with mcloud's Apple Music design, rewritten in Rust for speed: starts in under 300 ms and uses about 220 MB of memory. | Rust, egui |

## Get mcloud

[Spicetify](https://spicetify.app/docs/getting-started) must be installed first. Then install mcloud from the Spicetify **Marketplace**, or run:

**macOS / Linux**

```sh
curl -fsSL https://raw.githubusercontent.com/mcloudHQ/mcloud/main/install.sh | sh
```

**Windows** (PowerShell, not as administrator)

```powershell
iwr -useb https://raw.githubusercontent.com/mcloudHQ/mcloud/main/install.ps1 | iex
```

## Get mcloudfast

Build it from source with Rust; see the [mcloudfast README](https://github.com/mcloudHQ/mcloudfast#readme).
